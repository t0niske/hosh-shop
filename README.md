# HOSH — аромат для дома и бизнеса по подписке

Магазин подписок без менеджера: выбрал, оформил, привезли. Для дома и микробизнеса. Дизайн прежний (кобальт, кремовые волнистые карточки, Dela Gothic One + Manrope), многостраничный сайт под SEO.

Сайт: https://t0niske.github.io/hosh-shop/

## Структура (57 страниц)
- `/` — главная: «Аромат для дома и бизнеса по подписке», цена, хиты «как в …», цена 2 × 3, вопросы
- `/podpiska/` — конструктор и оформление на одной странице: аппарат → срок → аромат → имя, телефон, адрес, день доставки, оплата (Kaspi / карта / счёт). Предвыбор из ссылки: `?dev=nova1000&term=1&scent=17`
- `/diffuzor-dlya-doma/` — «Аромадиффузор для дома по подписке»
- `/kak-v-otele/` — «Аромат для дома как в отеле», шесть отельных ароматов
- `/nova-300/`, `/nova-1000/` — «Диффузор для квартиры» и «для большого дома и бизнеса» (Product, AggregateOffer)
- `/aromaty/` + 34 страницы ароматов с метками (настроение, семейство, ноты, «по мотивам …»)
- `/aromat-dlya/` + 10 подборок «Аромат для …»
- `/dostavka-i-oplata/` (Kaspi, отказ и возврат, переезд), `/voprosy/`, `/kontakty/`

## Настройки — `src/config.js`
- `contacts` — свои телефон, WhatsApp и адрес HOSH; пока пусто, берутся общие из `lib/data.js`
- `analytics.ga4`, `analytics.metrika` — ID счётчиков; пока пусто, скрипты не подключаются
- `checkout.online` — `false`: кнопка «Оформить», заказ уходит в WhatsApp, ссылку на оплату Kaspi присылает менеджер; `true` + `payUrl` — после подключения эквайринга
- `trial`, `swap`, `rules` — тест 3 дня, смена аромата, отказ, возврат, переезд (заготовки, подтвердить)
- `hits`, `heroHits` — хиты на главной; `mood`, `motif` — метки ароматов
- `extraScents` — Hilton и Massimo Dutti «по мотивам» (ноты — заготовка, подтвердить у поставщика; `enabled: false` прячет)

`src/setup.js` применяет конфиг к общим данным только внутри сборки HOSH — `lib/data.js` не меняется.

## События аналитики
`view_item` (страница аромата), `add_to_cart` («Выбрать», выбор аромата в конструкторе), `begin_checkout` (первое поле оформления), `add_payment_info` (способ оплаты), `generate_lead` (оформление без онлайн-оплаты), `purchase` (при `checkout.online`), `wa_help` («Помогите выбрать» и WhatsApp). Без ID счётчиков события копятся в `dataLayer`.

## Как править
Тексты — `src/pages.js`, `src/texts.js`, `src/niches.js`; блоки — `src/ui.js`; стиль — `src/assets/css/style.css`; конструктор — `src/assets/js/builder.js`; общее (меню, фильтры, события) — `src/assets/js/main.js`. Картинки и промпты — `IMAGES.md`.
```
node build.js
```
