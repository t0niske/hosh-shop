# HOSH — подписка на аромат

Магазин подписок: смелый синий фон, волнистые карточки, постерная типографика. Покупатель собирает подписку: аппарат → срок → аромат, кладёт в корзину и оформляет заказ в WhatsApp.

**Сайт:** https://t0niske.github.io/hosh-shop/

## Что на странице
- Заставка «HOSH распыляет аромат», постерный первый экран с наклейкой «3 дня бесплатно»
- Как это работает (4 шага)
- Конструктор: Nova 300 / Nova 1000, количество, срок 1/3/6 месяцев, выбор из 32 ароматов с фильтром
- Сводка: цена в месяц, экономия, итог за период
- Корзина (сохраняется в браузере) и оформление заказа в WhatsApp с полным списком позиций
- Факты, «для кого», FAQ, контакты

## Как менять данные
Цены, ароматы, контакты, FAQ — `js/data.js`.

## Структура
`index.html` · `css/style.css` · `js/data.js` · `js/led.js` · `js/main.js`.
