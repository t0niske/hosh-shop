Ароматдля отеля

Гость запоминает отель по первому вдоху в лобби. Отельные композиции созданы именно для этого момента.

В каталоге есть целое семейство отельных ароматов: белый чай, инжир, мускус, тёплое дерево. Они узнаваемые, спокойные и звучат дорого.

Лобби до 1000 м² закрывает Nova 1000 — его можно включать по расписанию со смартфона. Для коридоров этажей и небольших гостиниц достаточно Nova 300.
